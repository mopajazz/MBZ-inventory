# MBZ to Canvas Migration Console

Open this file in Chrome or Edge:

```text
C:\Users\j.warren\Desktop\MBZ migration\index.html
```

The app reads Moodle `.mbz`, `.tgz`, `.tar`, or `.gz` backups, or an already extracted Moodle backup folder. It parses content locally in the browser and does not upload course files.

## What It Does

- Preflight course audit
- Canvas readiness scoring
- Broken link and embedded media detection
- Moodle section to Canvas module mapping
- Quiz and question-bank triage
- HTML cleanup planning
- Accessibility review
- Assignment setting review
- Faculty review packet export
- Batch JSON export

Use **Try Sample** first to preview the workflow.
